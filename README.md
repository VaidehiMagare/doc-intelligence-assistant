# AI-Powered Document Intelligence Assistant

A Retrieval-Augmented Generation (RAG) application that allows users to upload documents and ask questions with answers grounded in document content.

## Planned Tech Stack

- Frontend: Next.js, TypeScript, Tailwind CSS
- Backend: FastAPI, Python
- Database: PostgreSQL with pgvector
- Infrastructure: Docker Compose

## Planned Features

- Document upload and text extraction
- Document chunking and embedding generation
- Semantic search and retrieval
- AI-generated answers with source citations
- User authentication and document isolation
